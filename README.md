# 算法小故事

让学习算法变得简单有趣：每个算法一个小故事，加一个可以动手玩的网页演示，分「初级到高级」几个等级。

## 已完成

| 算法 | 故事 | 演示 | 等级 |
|---|---|---|---|
| [二分查找](algorithms/binary-search/) | 小邮差找信箱 | 网页 | 初级、高级 |
| [冒泡排序](algorithms/bubble-sort/) | 排队拍合照 | 网页 | 初级、高级 |

在浏览器中打开各目录下的 `index.html` 即可体验。完整的候选算法清单见 [docs/algorithm-catalog.md](docs/algorithm-catalog.md)。整体规划和路线图见 [docs/project-plan.md](docs/project-plan.md)。

## 等级

| 等级 | 对象 | 学习方式 |
|---|---|---|
| 初级 | 小朋友 | 故事加点选和拖拽，不写代码 |
| 进阶 | 初学者 | 可视化加逻辑拼接 |
| 中级 | 在校生、转行者 | 可视化加简单代码 |
| 高级 | IT 从业者 | 逐步执行、代码、复杂度对比、工程应用 |

## 路线

1. 通读各类算法，整理资料
2. 每个算法写成故事，并做演示页
3. 发布到 GitHub 和各类博客
4. 网页稳定后集成到 App

## 新增一个算法

复制 `algorithms/binary-search/` 的结构，详见 `CLAUDE.md` 中的目录约定。
