# 栈：小熊叠盘子

小熊家的盘子洗干净以后，要一个一个叠在桌上晾干。

小熊先放上画着星星的 ⭐ 盘，再把月亮 🌙 盘叠在它上面，最后放上爱心 ❤️ 盘。现在桌上是高高的一摞：⭐ 在最下面，❤️ 在最上面。

妈妈说：「拿一个盘子来装饼干。」小熊伸手一拿，拿到的是 ❤️ 盘。为什么不是 ⭐ 盘？因为 ⭐ 盘被压在最下面，硬抽出来，整摞盘子都会倒。**只能拿最上面的那个。**

接着小熊又洗好一个小花 🌸 盘，放到了最上面。

吃完饼干要摆桌子了，小熊把盘子一个一个拿下来：

- 第 1 个拿到 🌸 盘，它是刚刚才放上去的。
- 第 2 个拿到 🌙 盘。
- 第 3 个，终于轮到 ⭐ 盘。

小熊数了数，拿走的顺序是 ❤️ 🌸 🌙 ⭐。最早放上去的 ⭐ 盘，等到最后才拿到；最晚放上去的 🌸 盘，几乎是一放上去就被拿走了。

**后放的先拿，先放的后拿。** 这样一摞只能从上面放、从上面拿的东西，就叫「栈」。

小熊还玩了一个拼积木的游戏：左半块 `(` `[` `{` 先叠进篮子，右半块 `)` `]` `}` 来了，就要和篮子里最上面那块拼成一整块。形状对不上，或者篮子空了，就拼不下去；拼到最后篮子里还剩积木，也不算拼完。这就是电脑检查括号有没有写对的办法。

## 故事背后的算法

- 栈只有一头能进出：放进去叫入栈（push），拿出来叫出栈（pop），最上面那个叫栈顶。
- 放、拿、看栈顶，都只碰最上面那一个，不管栈里有多少东西，都是一步完成，时间 O(1)。
- 检查括号：从左往右看，左括号入栈；右括号必须和栈顶是同一种，配上就出栈；最后栈要是空的。整个串只扫一遍，时间 O(n)。
- 最容易写错的三处：右括号来时没看栈空不空、最后没看栈空不空、配对时没看种类对不对。

## 在生活和工程里

- 叠书、羽毛球筒、一层层穿衣服再反过来脱，都是后进先出。
- 程序调用函数时，把每一层调用压进「调用栈」，返回时一层层弹出；递归太深把栈用完，Kotlin 和 Java 里就会抛出 `StackOverflowError`。
- 编辑器的撤销：每次修改压进栈里，按一次撤销就弹出最近的一次。
- 浏览器的后退按钮、计算器算表达式、迷宫里的深度优先搜索，背后也是栈。
