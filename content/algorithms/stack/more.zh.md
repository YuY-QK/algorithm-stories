## ⚡ 为什么快

放、拿、看栈顶，都只碰最上面那一个，不管栈里有多少东西都是一步，时间 O(1)。用数组实现时，满了换一个两倍大的数组，偶尔要拷贝一次，平均下来每次 push 仍是 O(1)。

## 🧠 为什么非用栈不可

只有一种括号时，数一数「还有几个左括号没配上」就够了，一个计数器搞定。有三种括号时，右括号要和「最近一个还没配上的左括号」比种类，这个「最近一个」正是栈顶。

## 🌍 真实世界里的栈

- 函数调用栈：每调用一个函数，就压进一个栈帧（参数、局部变量、返回地址），函数返回时弹出。递归太深把栈用完，Kotlin 和 Java 里就抛 `StackOverflowError`。
- JVM 字节码是基于栈的：`iadd` 这样的指令从操作数栈弹出两个数，把和压回去。
- 编辑器的撤销和重做：每次修改压进撤销栈；撤销时弹出来，压进重做栈。
- 浏览器的后退和前进，可以看成两个栈。
- 表达式求值：Dijkstra 的调度场算法用栈把 `(2 + 1) * 3` 变成逆波兰式 `2 1 + 3 *`，再用栈算出结果。
- 深度优先搜索：走迷宫时把岔路口压进栈，走进死胡同就弹出，回到最近的岔路口。

## 🛠️ Kotlin 里怎么用

直接用标准库的 `ArrayDeque`：`addLast` 入栈，`removeLast` 出栈，`last()` 看栈顶，栈可能空时用 `removeLastOrNull()`。Java 的老类 `java.util.Stack` 继承自 `Vector`，官方文档建议改用 `Deque`。

## 🔀 常见变种

- 最小栈：再配一个栈记录「到目前为止的最小值」，随时 O(1) 拿到最小值（LeetCode 155）。
- 单调栈：栈里保持递增或递减，用来找「右边第一个比我大的数」、柱状图里最大的矩形。
- 用两个栈做一个队列：一个只进、一个只出，倒一次顺序就反过来了。
