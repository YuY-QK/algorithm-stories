# 归并排序：两队合一队

动物学校运动会，要按身高排队。两个班的小动物已经各自排好了队，矮的在前：

- 一班：2、5、6
- 二班：1、3、4

现在要合成一队。办法很简单：**只看两个队头，矮的先走**。

- 2 和 1 比，1 矮，先走。
- 2 和 3 比，2 矮，先走。
- 5 和 3 比，3 矮，先走。
- 5 和 4 比，4 矮，先走。
- 二班没人了，一班剩下的 5、6 直接跟上。

合成一队啦：1、2、3、4、5、6。只比了 4 次，因为每次只看两个队头，不用把所有人比来比去。

可是，这两个班一开始是怎么排好的呢？倒回去看。

原来的队伍是 5、2、6、1、4、3，乱七八糟。我们**一刀切成两半**：5、2、6 和 1、4、3。再对半分：5 | 2、6，1 | 4、3。最后每队只剩 1 个，**1 个小动物当然是排好的**。

然后倒着走：两两合并。2、6 合成一队，4、3 合成 3、4；5 加上 2、6 合成 2、5、6，1 加上 3、4 合成 1、3、4；最后这两队，就是开头那两个班，合成 1、2、3、4、5、6。

不管多长的队伍，都是这个办法：**先分，分到不能再分；再合，合的时候只比队头**。

## 故事背后的算法

- 做法：把区间从中间分成两半，递归地把两半各自排好，再把两个有序的半边合并成一个。合并时用两个指针指着两边的队头，每次取较小的放进临时数组，一边用完后另一边直接接上，最后抄回原数组。
- 代价：n 个数一共分 log₂n 层，每一层合并加起来最多比较 n 次，所以不管输入什么样，都是 O(n log n)。要一个 O(n) 的临时数组。
- 性质：稳定。两边队头相等时取左边的，相等的元素不会换顺序。

## 在生活和工程里

- 两摞已经按日期排好的单据，合成一摞，只要看两摞最上面的那张。
- Java 给对象排序用的 TimSort 和 Python 的 `list.sort`，都是归并排序的改进版，稳定。
- 数据比内存还大时，先把数据分成小块各自排好，再用合并的办法把所有块合成一个，这叫外部排序。
