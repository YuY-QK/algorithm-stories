# 快速排序：体育课排队

体育课上，8 个同学站成一排，高矮不齐，身高是 6、2、8、4、1、7、3、5。体育老师要把他们按身高从矮到高排好。

老师的办法很省事：**先选一位同学当标杆，把大家分成两边，剩下的事交给两边自己**。

- 老师点了最右边的 5 当标杆 🚩。
- 从左到右，一个一个和标杆比身高。6 比标杆高，先留着；2 比标杆矮，去左边那队；8 高，留着；4 矮，去左边；1 矮，去左边；7 高，留着；3 矮，去左边。
- 全问完了，标杆和高队的第一位换个位置。现在：左边是 2、4、1、3，都比 5 矮；右边是 7、6、8，都比 5 高。**5 已经站在了最终的位置，不用再动了**。

左边四位还乱着？没关系，他们是一个更小的队伍：再选一位标杆，再分两边。右边三位也一样。分着分着，队伍越来越小，小到只剩一个人时，他就站定了。一共和标杆比了 14 次身高，8 个同学就都排好了。

标杆选得好不好，差别很大。如果每次选到的恰好是中间身高的同学，队伍每次都被劈成差不多大的两半，很快就分完。如果每次选到的都是最矮或最高的，一边是空的，另一边只少了一个人，要分很多很多轮。最倒霉的是：队伍本来就排得整整齐齐，老师却每次都点最右边的最高的同学，每一轮只站定一个人。

## 故事背后的算法

- 做法：选一个标杆（这里用最右边的），分区：比它小的放左边，不比它小的放右边，标杆放在中间，它就站在了最终的位置。再对左右两个区间各做一次，区间只剩 0 或 1 个元素时停止。这个分区写法叫 Lomuto 分区。
- 代价：每次分区要把区间里每个元素和标杆比一次。标杆分得均匀时一共约 n log n 次，是 O(n log n)；标杆总是最大或最小时是 n(n − 1)/2 次，是 O(n²)。
- 性质：原地排序；不稳定（隔着很远的交换会改变相等元素的先后顺序）。

## 在生活和工程里

- 老师把一班同学按身高分成「比他矮的」和「比他高的」，再各自分下去；超市把货按价格分成「比这件便宜的」「比这件贵的」。
- Java 的 `Arrays.sort(int[])`（Kotlin 的 `IntArray.sort()` 在 JVM 上就是调它）用的是双轴快速排序；C++ 的 `std::sort` 是快速排序加堆排序和插入排序的混合。
- 同一个分区的办法还能用来找第 k 小：每次只管有答案的那一边，另一边扔掉，不用全部排好，这叫快速选择。
