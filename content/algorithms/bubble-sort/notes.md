# 冒泡排序：资料

## 1. 解决什么问题

把一组可以比较大小的数据从小到大排好。它是最容易理解的排序算法之一，主要价值在于教学。

## 2. 核心思路

1. 从左到右依次比较相邻的两个元素。
2. 左边的比右边大就交换。
3. 走完一轮，剩下元素里最大的那个一定被换到了最右边，位置固定。
4. 对还没固定的部分重复，每轮少看一个。
5. 某一轮一次都没交换，说明已经有序，提前结束。

## 3. 复杂度和性质

| 项目 | 值 |
|---|---|
| 时间（最好） | O(n)，已经有序时只走一轮，比较 n−1 次（需要「提前退出」优化） |
| 时间（平均、最坏） | O(n²)，最坏（逆序）比较和交换都是 n(n−1)/2 次 |
| 空间 | O(1)，原地排序 |
| 稳定性 | 稳定（比较用 `>`，相等时不交换） |
| 适应性 | 有「提前退出」时，对几乎有序的数据很快 |

具体数字：5 个元素最坏比较 10 次，100 个 4950 次，1 万个约 5000 万次，10 万个约 50 亿次。

## 4. 常见变种和易错点

**变种**

- 提前退出：记录一轮里有没有交换（演示页用的就是这个版本）。
- 记录最后一次交换的位置：它之后的部分都已有序，下一轮只需比到那里。
- 鸡尾酒排序（双向冒泡）：一轮从左往右，下一轮从右往左，对「小元素在末尾」的数据更快。
- 奇偶排序：先比所有 (奇, 偶) 下标对，再比 (偶, 奇) 对，适合并行。

**易错点**（演示页高级档讲了前三条）

1. 内层循环上界应是 `n - 1 - i`。写成 `n - 1` 结果正确但做了很多无用比较；写成 `n` 会访问 `a[j + 1]` 越界。
2. 比较写成 `>=` 会在相等时交换，排序变得不稳定。
3. 不加 `swapped` 标志，已有序的数据也要比较 n(n−1)/2 次。
4. 外层循环写成 `range(n)` 多走一轮，不出错但多余；`swapped` 要在每一轮开始时重置，放在外层循环外面会导致提前退出失效。

## 5. 真实应用

**生活**

- 排队拍合照、整理书架：手动排序时人们常常就是「看相邻两个，不对就换」。
- 体育课按身高站队，老师让相邻同学比一比。

**工程**

- 教学和面试：理解比较、交换、稳定性、复杂度最直观的入门例子。
- 真正的排序都不用它：Python 的 `sorted` 和 `list.sort` 用 Timsort；Java 对基本类型数组用双轴快速排序、对对象数组用 TimSort。
- 「几乎有序的小数据做局部调整」这类场景会用到类似「相邻比较交换」的思路，但更常见的是插入排序（例如 Timsort 对短片段就用二分插入排序）。故事稿里「嵌入式或图形程序会用冒泡思路」这句缺具体出处，待核实，建议改成插入排序的例子。

## 6. 分级讲法建议

| 等级 | 讲法 |
|---|---|
| 初级 | 排队拍合照：小朋友判断相邻两人要不要换，答错有提示。（已完成） |
| 进阶 | 把「比较」「交换」「本轮结束」「一轮没换就停」做成积木，让用户拼出算法，再用 6 个人验证。 |
| 中级 | 代码填空：内层循环上界、比较符号、`swapped` 的位置；给一组有相同身高的数据，观察 `>` 和 `>=` 的区别（稳定性）。 |
| 高级 | 逐步执行、跳到本轮结束、三种初始顺序对比、和 n·log n 的量级对比、四个要点。（已完成）可以再加「和插入排序比较交换次数」。 |
