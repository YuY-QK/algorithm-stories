# 广度优先搜索（BFS）：资料

## 1. 解决什么问题

在一张图（迷宫的格子、社交网络里的人、网页之间的链接）里，从一个起点出发，按「离起点几步」由近到远地访问所有能到的点。最常见的用途：**每条边一样长（无权图）时，求起点到其他点的最少步数和最短路线**。

## 2. 核心思路

1. 起点放进队列，标记「来过了」，距离是 0。
2. 从队首取出一个格子，看它上下左右四个邻居。
3. 邻居没出界、不是墙、没来过，就标记来过、距离 = 当前 + 1、放进队尾。
4. 重复 2、3，直到队列空了（走遍了），或者取出的就是终点。

队列先进先出，所以离起点 k 步的格子一定都在 k + 1 步的格子前面出队，处理顺序就像水波：一圈一圈往外扩。关卡「看」里的水波就是按层的写法（一次处理一整圈），和用队列一个一个处理是同一个顺序。

**为什么第一次碰到终点就是最短**：用归纳法看，出队顺序按距离不减（队列里任何时刻最多只有 d 和 d + 1 两种距离，前面都是 d）。一个格子第一次被发现时，发现它的格子是所有邻居里最早出队的，也就是距离最小的那个，所以它的距离 = 最小邻居距离 + 1，正好是最短距离。前提是每一步代价相同；边有不同长度时要用 Dijkstra。

## 3. 复杂度和性质

| 项目 | 值 |
|---|---|
| 时间 | O(V + E)：每个点最多入队、出队一次，每条边最多看两次（无向图） |
| 网格上 | V = h·w 个格子，每格 4 个方向，E ≤ 4V，所以 O(h·w) |
| 空间 | O(V)：visited/dist 数组加上队列，队列最长时可能装下一整「圈」 |
| 最短路 | 无权图（或所有边权相同）时得到最短路；有权图不行 |
| 完备性 | 有限图里一定能找到能到的终点；走不到时把能到的点走完就停 |

和深度优先（DFS）对比：

| | BFS | DFS |
|---|---|---|
| 容器 | 队列（先进先出） | 栈或递归（后进先出） |
| 顺序 | 由近到远，一圈一圈 | 一条路走到底再回头 |
| 最短路 | 无权图上第一次到达就是最短 | 第一次到达的路不一定最短 |
| 额外空间 | 和最宽的一层有关 | 和最深的一条路有关 |
| 常见用途 | 最少步数、按层处理、几度好友 | 连通性、拓扑排序、回溯、找环 |

## 4. 常见变种和易错点

**变种**

- 返回路线：入队时记下 `parent`（从哪一格来的），到终点后顺着 parent 倒着走回起点再翻转。（Kotlin 练习的第二题）
- 多源 BFS：一开始把所有起点一起放进队列（距离都是 0），求每个格子到「最近的起点」的距离，例如 LeetCode 994「腐烂的橘子」、542「01 矩阵」。
- 按层处理：每轮先记下队列长度 `size`，一次处理 `size` 个，适合「第几层有哪些点」这类问题（如二叉树层序遍历）。
- 0-1 BFS：边权只有 0 和 1 时用双端队列，权 0 的边放队首、权 1 的放队尾。
- 双向 BFS：从起点和终点同时扩展，两边相遇就停，搜索的点数通常少得多。

**易错点**（关卡「找 bug」讲了前三条）

1. **忘记检查 visited**：`if (grid[nr][nc] == '#') continue` 只挡墙不挡走过的格子，同一格反复入队，队列指数增长（5×5 空房间几百步内队列就超过 40 个），dist 也被反复改写。
2. **用栈代替队列**：`queue.removeLast()` 取队尾，变成深度优先的顺序；格子第一次被发现时的距离不一定最短。演示迷宫 4×4 空房间，奶酪在起点正下方 3 步，栈版本返回 9。
3. **边界写成 `0..h`**：Kotlin 的 `0..h` 包括 h，`0 until h` 才不包括。走到最下面一行再往下看时 `grid[h]` 越界崩溃。
4. **出队时才标记 visited**：只在 `removeFirst()` 之后标记，同一个格子在被处理前可能被多个邻居重复入队。结果仍然正确（重复的那份出队时会被跳过，前提是出队时检查了），但队列变长、做了重复工作；如果出队时也不检查，就会重复扩展。入队时标记是标准写法。
5. **在入队时判断终点并直接返回**：可以，而且能省一点时间，但要注意起点本身就是终点的情况。本关代码在出队时判断，和「水波」讲法一致。
6. **dist 数组的初值**：Kotlin `IntArray(w)` 默认是 0，所以本关用单独的 `visited` 数组；也可以把 dist 初始化为 -1 同时当 visited 用（Python 参考实现就是这样）。

## 5. 真实应用

- **迷宫和网格寻路**：游戏里格子地图上找最少步数，BFS 是最基础的做法；带不同地形代价时用 Dijkstra，再加上「估计还有多远」就是 A*。
- **电路布线**：C. Y. Lee 1961 年把 Moore 的迷宫算法用在电路板布线上（Lee 算法），在格子上从一个引脚向外一圈圈扩展，找到另一个引脚的最短连线。
- **垃圾回收**：Cheney 1970 年的复制式回收器按广度优先复制所有能访问到的对象：to-space 本身就当队列用，一个 scan 指针追着 free 指针走，两者相遇就复制完了，不需要额外的栈或递归。（很多「标记-清除」回收器的标记阶段用的是栈，也就是深度优先，并不都是 BFS。）
- **网页爬虫**：从种子网页出发，按链接的「层」一层层抓。Najork 和 Wiener 2001 年在 WWW 会议上的论文《Breadth-first crawling yields high-quality pages》发现，广度优先的抓取顺序会比较早地抓到重要（PageRank 高）的网页。现代爬虫的调度策略更复杂（优先级、礼貌间隔等），不是纯 BFS。
- **社交网络「几度好友」**：一度好友是直接相连的人，二度是好友的好友……这正好是从你出发的 BFS 层数。小规模可以直接 BFS；超大网络上统计平均距离用的是近似算法（例如 Facebook 2016 年「三度半分隔」的研究）。
- **其他**：二叉树层序遍历、判断二分图（BFS 染色）、网络广播、无权图上的最短跳数（如路由跳数）、求连通分量。

## 6. 历史

- Konrad Zuse 1945 年在关于 Plankalkül 的博士论文（被拒、1972 年才出版）里提出了 BFS，用来求图的连通分量。
- Edward F. Moore 1959 年发表《The shortest path through a maze》，用它找迷宫最短路（1957 年的一次研讨会上提出，1959 年出版）。
- C. Y. Lee 1961 年《An Algorithm for Path Connections and Its Applications》把它用于布线。

## 7. 关卡讲法建议

| 步骤 | 讲法 |
|---|---|
| 看 | 小老鼠 🐭 在 7×7 迷宫中间，奶酪 🧀 在角上。水波一圈圈扩：1 步能到的格子写 1，2 步写 2……碰到奶酪那一圈停，倒着数 6 → 5 → … → 0 走回来，就是最短路。 |
| 玩 | ①「下一圈」：孩子当水波，点出下一圈的格子；每圈格子数用小圆点提示，点太远的格子时上一圈透光。②「抄近路」：孩子一格格点出路线，到奶酪后和水波比步数；绕远了就亮出水波的路，还可以带着水波数字再走一次。 |
| 做 | 逐步执行（显示队列内容）、猜下一步（出队后哪些邻居入队）、找 bug（不查 visited、用栈、`0..h` 越界）、亲手写 `shortestPath` 和 `shortestRoute`、挑战（11×11 迷宫凭眼力画最短路）。 |
| 延伸 | O(V + E)、为什么最短、和 DFS 对比、真实用途。 |
