# 队列：奶茶店排队

街角新开了一家奶茶店。店门口摆着 6 把椅子，编号从 0 到 5，排成一排。店里只有一位店员，规矩只有一条：**先来的先买**。

🐼 第一个来，坐到 0 号椅子。🐰 和 🐱 也来了，一个接一个往后坐，坐 1 号和 2 号。

店员做好第一杯，只叫坐在最前面的那位，也就是**队头**：🐼 先买到 🧋，起身走了。新来的 🐶 不能插队，坐到最后一位的后面，也就是**队尾**，3 号椅子。下一杯是 🐰 的，先来的先买。接着 🦊 和 🐸 来了，坐上 4 号和 5 号，最后两把椅子。

这时 🐨 来了，可是后面已经没有椅子了。回头一看，前面的 0 号、1 号椅子空着，是 🐼 和 🐰 买完走掉留下的。难道让大家都站起来往前挪一挪？太麻烦了。

店员想了个好办法：**把椅子围成一圈**。5 号椅子的下一把，就是 0 号椅子。🐨 坐到 0 号，排在 🐸 后面。

🐱 买到奶茶，队头往前挪一把。🐵 和 🐯 接着来，坐 1 号和 2 号。6 把椅子全坐满了。🐷 来晚了一步：椅子坐满了，只好在门外等一等。

店员一杯接一杯地做：🐶、🦊、🐸 依次买到奶茶。买到的顺序，正好就是来的顺序。椅子转着圈用，谁也不用挪位置，后来的人一直有得坐。

## 故事背后的算法

- 排队的规则叫**队列**：新来的放到队尾（入队 offer），只从队头取走（出队 poll），先进先出。
- 6 把椅子是一个容量为 6 的数组。`head` 指向队头那把椅子，`tail` 指向下一个人要坐的空椅子。
- 椅子围成一圈，就是让下标走到末尾后绕回 0：`tail = (tail + 1) % 6`。这叫**循环队列**，入队、出队都只动一个下标，不用挪别人，都是 O(1)。
- 椅子坐满时（人数等于容量）就不能再入队。空和满的时候 `head` 都等于 `tail`，所以还要记着队里有几个人，才分得清。

## 在生活和工程里

- 排队买东西、银行叫号、打印机一份一份打印：都是先来先处理。
- 键盘缓冲区：按得太快时，按键先存进一个环形缓冲区，程序按顺序取。
- Java 和 Kotlin 的 `ArrayDeque`、Java 的 `ArrayBlockingQueue`：里面就是一圈「椅子」，`head` 和 `tail` 绕着圈走。
- 广度优先搜索：用队列一层一层往外找，先找到的离起点最近。
