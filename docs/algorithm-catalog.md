路线第 1 步「通读各类算法，整理资料」的总表。每一行是一个候选算法，配一个故事点子和适合的等级。
做完一个就把状态改成「已完成」，并在根目录 `README.md` 的表格里登记。

## 推进顺序建议

1. 先把「排序」和「搜索与图」各做 1 个（冒泡排序、BFS 走迷宫），检验目录结构对不同类型的算法是否适用。
2. 再补齐小朋友能玩的初级内容：顺序查找、选择排序、栈、队列、贪心。
3. 积累到 8 到 10 个后，做一个首页把所有算法按等级串起来，再开始发博客。

新增算法的流程：`algorithm-researcher` 整理资料 → `story-writer` 写故事 → `demo-builder` 做演示 → `content-reviewer` 审校（这四个 agent 在 `.claude/agents/`）。
