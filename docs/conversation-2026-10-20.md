## 1. 想法

**用户**：我想要做这样一个项目，让学习算法变得简单有趣。

**讨论的方向**
- 可视化演示：排序、图遍历、动态规划的每一步动起来，可单步、调速、改输入（参考 VisuAlgo）
- 游戏化闯关：用 BFS 帮角色走迷宫、用贪心经营小店
- 生活类比：「整理书架」「排队买奶茶」引入，再过渡到代码
- 题目加即时反馈：错了能看到错在哪一步
- 内容型：漫画、短视频、系列文章

倾向：可视化加小游戏的组合；第一版做小，先验证是否有趣。

## 2. 分级和平台

**用户**：我希望可以分等级，初级～高级，初级适合小孩子，可以简单一些，高级的适合 IT 行业的人，前期先做网页，后期可以再集成到 app。

**定下的等级**

| 等级 | 对象 | 学习方式 | 示例内容 |
|---|---|---|---|
| 初级 | 小朋友 | 故事加拖拽、点选，不写代码 | 整理玩具学排序、猜数字学二分、走迷宫学搜索 |
| 进阶 | 初学者、青少年 | 可视化加积木式拼接逻辑 | 冒泡、选择排序，栈和队列，简单递归 |
| 中级 | 在校生、转行者 | 可视化加简单代码，自动评测 | 链表、树、BFS/DFS、哈希表，复杂度直观理解 |
| 高级 | IT 从业者 | 真实代码加性能对比，面试和工程场景 | 动态规划、图算法、字符串匹配、LRU、一致性哈希 |

**设计原则**
- 每个算法统一结构：生活场景 → 动画演示 → 自己动手 → 代码和复杂度。小孩停在前面，高级用户继续深入。
- 游戏化元素（进度、星星、徽章）各等级都有，小孩偏画面和故事，高级偏挑战和对比。
- 同一个算法在不同等级重复出现，深度不同。

**技术方向**
- 前端可用 React 或 Vue 加 TypeScript，动画用 Canvas 或 SVG
- 响应式网页并做成 PWA；之后上架可用 Capacitor 或 React Native 复用代码
- 算法核心逻辑（每一步的状态变化）与界面分开，做成可复用的「算法引擎」

## 3. 先做原型

**用户**：先做原型进行验证，然后再细化。

**做了什么**：二分查找单页原型，两档可切换。
- 初级「小邮差找信箱」：用户心里想 1～100 的号码，小邮差每次猜中间，用户回答更小、更大或就是它。信箱逐格变暗，最多 7 次猜中。支持撤销和提示矛盾的处理。
- 高级「逐步执行」：可改数组大小（8/16/32）和目标值，单步或自动播放；lo、mid、hi 指针与 Python 代码当前行同步高亮；顺序查找与二分查找的比较次数对比（对数刻度）；写对二分的三个坑。
- 验证：初级对 1～100 每个号码都不超过 7 次；高级对 2000 组随机数组（命中和未命中）执行过程都正确。

**待用户反馈的两个问题**
1. 初级的讲法，小朋友会不会觉得有趣？
2. 高级这档对工程师来说深度够不够？
